# Task Tracker CLI

A simple command-line task tracker built with Node.js.

This project allows users to add, update, delete, and manage tasks directly from the terminal. Tasks are stored in a JSON file.

## Features

- Add a new task
- List all tasks
- List tasks by status
- Find a task by ID
- Update a task description
- Delete a task
- Mark a task as done
- Mark a task as in-progress
- Store tasks permanently in a JSON file
- Automatically track task creation and update times

## Technologies Used

- Node.js
- JavaScript
- File System (`fs`)
- JSON

No external npm packages are required.
